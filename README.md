# 「词来」· 课堂生词速查与课后闪卡助手 (Desktop)

专门为线上 1 对 1 / 1 对 2 对外汉语教学打造的高效桌面原生伴侣应用（Electron + Python 本地伴侣服务）。

---

## 核心特性

1. **规整对称顶栏**：4 列等宽网格（Grid）布局，锁定 38px 统一高度，自适应不同屏幕尺寸与窄屏单列滑动。
2. **61 种二外洲际语言库**：按「欧洲、亚洲与中东、美洲、非洲」四大板块归类，自带即打即搜与星标常用收藏置顶。
3. **双语翻译体系**：英文翻译必备，二翻为学生母语并列对照（支持通义千问、Gemini、Google Cloud Translation 与离线词库）。
4. **超拟人神经网络发音体系**：接入豆包大模型 2.0（爽快思思、Vivi、云舟）与微软神经语音（晓晓、云希），告别机械发音。
5. **地道生活例句与 AI 随堂练习**：实时生成买菜、问路、职场生活例句，多题型（选词填空、语境填空、情境问答）一键出题与做题/备课版复制。
6. **极速一键复制**：一键生成排版工整的双语生词卡，无缝粘贴至 Preply / Zoom 等任意线上教学聊天框。
7. **课后一键闪卡交付**：下课点击一键导出学生专属 3D 拟物翻转复习闪卡（单 HTML 文件，离线即开，内置发音与自测）。
8. **3D C4D 粘土拟物质感**：全套采用柔光圆润的 3D 粘土拟物图标与赤陶暖纸配色。

---

## 架构与安装运行

### 快速体验
在 macOS 上双击运行打包后的 `/Users/a1/Desktop/词来.app` 即可。

### 源码打包构建
```bash
npm install
npm run package:mac
```
构建产物将输出至 `dist/词来-darwin-arm64/词来.app` 并自动同步部署到 macOS 桌面。
